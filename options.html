网申自动填写助手 · 资料设置

资料文件与手动补充的字段都会保存在插件中，关闭浏览器或重启电脑后依然有效。

1. 资料文件

两种存放方式：① 把 Word 信息文档 与 PDF 简历 直接放进插件的 data/ 目录（默认文件名 info.docx / resume.pdf， 也可用 data/manifest.json 指定任意文件名）；② 在悬浮窗或本页上传。
替换 data/ 目录里的文件后，点“重新读取文件并解析”即可自动识别新内容；页面上悬浮窗也会自动检测文件变化。

2. 资料字段（可手动修改 / 补充，自动填写时优先使用）

3. 页面专有字段（在悬浮窗里补充过一次后自动记住）

4. 原始数据（高级 / 备份）

导出 / 导入 JSON
可以把资料导出备份，或把备份粘贴回来（只覆盖“手动补充”的部分与页面专有字段）。
