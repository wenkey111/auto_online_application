# 网申自动填写助手（Edge 浏览器插件）

读取本地的**网申信息文档（Word）**和**简历（PDF）**文字信息，在网申页面上点一下悬浮窗的「开始填写」，就能把页面表单自动填好；表单里出现资料里没有的字段时，悬浮窗会提示你补充，补一次之后永久记住。

所有解析都在你自己的浏览器里完成，插件不联网、不上传任何内容。

---

## 一、安装（Edge，一次性操作）

1. 把 `网申自动填写助手` 整个文件夹放到一个固定位置（例如 `D:\Edge插件\网申自动填写助手`），**不要放进临时目录**，因为插件会长期从这个目录读取资料文件。
2. 打开 Edge，地址栏输入 `edge://extensions/` 回车。
3. 打开左下角的「**开发人员模式**」开关。
4. 点「**加载解压缩的扩展**」，选择 `网申自动填写助手` 文件夹（选中文件夹本身，不是里面的文件）。
5. 看到「网申自动填写助手」卡片即安装成功。建议把它固定到工具栏（点浏览器右上角拼图图标 → 点插件右侧的图钉）。

> 升级/修改插件时：回到 `edge://extensions/` 点该卡片的「重新加载」。

---

## 二、把资料交给插件（两种方式，任选其一）

### 方式一：放进插件目录（最省事）

打开插件文件夹里的 `data` 目录：

```
网申自动填写助手/
└─ data/
   ├─ info.docx     ← 你的网申信息文档（Word）
   ├─ resume.pdf    ← 你的简历（PDF）
   ├─ manifest.json ← 文件名映射（可选）
   └─ README.txt    ← 说明
```

- 直接**用自己的文件覆盖** `info.docx` 与 `resume.pdf` 即可，示例文件可以删掉后放同名文件。
- 想用自己的文件名：编辑 `data/manifest.json`：

  ```json
  { "info": "我的网申信息表.docx", "resume": "张三-简历.pdf" }
  ```

- 支持格式：`.docx`、`.pdf`（能复制文字的 PDF）、`.txt`、`.md`。旧版 `.doc` 请先在 Word 里「另存为 .docx」。

### 方式二：在插件里上传

打开任意网页 → 悬浮窗 → 「上传 / 替换」按钮，或在插件设置页（悬浮窗「⚙ 资料设置」）上传。

上传的文件会保存在插件的浏览器存储中（`chrome.storage.local` + `unlimitedStorage`），**关闭浏览器、重启电脑后依然在**，并且优先于 `data/` 目录里的文件使用；想切回目录文件，点「用目录文件」。

> 小提示：未打包插件的身份与插件文件夹路径绑定。如果你把插件文件夹**换到别的路径**，等于换了一个新插件，之前「上传」的文件不会跟过去（只要在 `data/` 目录里的文件会跟着走）。想最稳，就用「方式一」把文件放在 `data/` 目录。

### 替换文件后会自动识别

插件按**文件内容哈希**判断资料有没有变化：

- 覆盖 `data/` 目录里的文件后，点悬浮窗的「↻ 重新读取文件」（或设置页的「重新读取文件并解析」），插件会立即重新解析；
- 也可以在浏览器里重新加载插件后再操作；
- 插件内上传的文件替换后会自动重新解析，无需其它操作；
- 手动补充过的字段（见下一节）在重新解析后**依然保留**。

## 三、在网申页面使用

1. 打开注册/登录/选岗之后的**网申信息填写页**。
2. 页面右侧一直有一个圆形悬浮球，点它展开面板（也可以点浏览器工具栏上的插件图标显示/隐藏悬浮窗）。
3. 点「**▶ 开始填写**」。插件会扫描当前页面（包括 iframe 内的表单），自动填写能识别的字段。
4. 面板会显示结果：
   - `已填写 N` —— 成功写入的字段数；
   - `已有内容 N` —— 页面上原本已有内容，默认不覆盖（勾选「覆盖页面已有内容」可重填）；
   - `缺数据 N` —— 页面要这个字段，但资料里没有 → 面板下方出现输入框，填一次「保存并填入」，会立刻写进页面，并永久记住；
   - `未识别 N` —— 字典里没有的页面专有字段（例如「意向事业部」「高考省份」）→ 同样在面板下方补一次，之后每次都会自动填。
5. 换到下一个页面（例如从「基本信息」切到「教育经历」）时，再点一次「开始填写」即可。

面板上的其他按钮：

| 按钮 | 作用 |
| --- | --- |
| `↻ 重新读取文件` | 重新检查 `data/` 目录文件是否有变化，有变化就重新解析 |
| `⚙ 资料设置` | 打开资料设置页：查看/修改每个字段、上传文件、导出导入资料 |
| 收起 `–` | 收成悬浮球，不挡页面 |
| 隐藏 `×` | 暂时隐藏悬浮窗（想再显示时点浏览器工具栏的插件图标） |

## 四、能识别的字段（覆盖常见网申信息表）

基本信息：姓名、姓/名、英文名、性别、出生日期、年龄、国籍、民族、政治面貌、入党时间、婚姻状况、健康状况、身高、体重、血型、身份证号、证件类型、户籍地址、户口性质、籍贯、生源地、省/市/区、现居住地址、邮编。

联系方式：手机号、固定电话、电子邮箱、微信、QQ、紧急联系人姓名/关系/电话。

教育背景：毕业院校、专业、学历学位、培养方式（全日制等）、入学时间、毕业时间、学号、GPA/平均分、专业排名、学校所在地、院校类型（985/211/双一流）、学位证书编号、是否应届、教育经历。

语言技能：外语水平、CET-4/6、计算机等级、资格证书、专业技能、获奖情况、自我评价、兴趣爱好。

经历：校园经历、社会实践、实习经历、工作经历、项目经历、培训经历、论文专利。

求职意向与其他：应聘岗位、期望工作城市、期望薪资、到岗时间、是否服从调剂、是否有亲属在本单位、招聘信息来源、备注。

家庭：父亲/母亲姓名、工作单位、电话，家庭成员。

> 不同单位的用词不一样，插件内置了同一字段的多种叫法（例如「手机号码 / 手机号 / 联系电话 / 移动电话 / 联系方式」都指向手机号）。遇到完全没见过的字段名，就在悬浮窗里补一次，插件会记住这个页面的字段名。

## 五、常见问题

**Q：页面上的字段没被填上？**
先看悬浮窗的提示：如果是「缺数据」，在面板里补一次即可；如果是「未识别」，说明这个字段名不在字典里，补一次后永久记住。也可能是页面用了特殊控件（例如需要一级一级选择的省市联动、只允许从弹层选择的自定义下拉、验证码、文件上传），这些需要手动完成。

**Q：会不会把页面原来的内容冲掉？**
默认不会：已有内容的输入框会被跳过并计入「已有内容」。需要覆盖时勾选面板底部的「覆盖页面已有内容」。

**Q：简历 PDF 提取不到文字？**
说明这个 PDF 是扫描件（图片型）。请用可复制文字的 PDF，或把简历另存为 `.docx` / `.txt` 后在插件里替换（简历位也支持 Word/txt）。

**Q：`.doc` 老格式能用吗？**
不能直接解析，请先在 Word 里「另存为」→ `Word 文档(*.docx)`。

**Q：悬浮窗挡住了页面按钮？**
拖动面板标题可以把面板挪到任意位置（下次打开仍在那个位置）；点「收起」变成小圆球，或点「×」完全隐藏。

**Q：插件要很多权限吗？**
只需要「存储」（保存资料）和「在所有网站上读取和更改数据」（这样才能在网申页面上填写表单）。插件不会把任何内容发到外部服务器。

**Q：能在 Chrome / 其它 Chromium 浏览器用吗？**
可以，安装方式相同（Chrome 用 `chrome://extensions/`）。

插件自带一个示例网申表单，方便你先验证效果：

1. `edge://extensions/` → 本插件「详情」→ 打开「**允许访问文件网址**」；
2. 双击打开插件目录下的 `test/demo-form.html`；

## 七、目录结构（给需要改代码的人）

```
manifest.json         插件清单（MV3）
background.js         后台：资料文件管理、哈希变更检测、消息路由
offscreen.html/js     解析文档的工作页（Word/PDF → 文本 → 资料对象）
content.js            页面侧：悬浮窗 UI、表单识别与自动填写、iframe 协同
options.html/js       资料设置页
lib/fields.js         字段字典（同义词、取值等价词、省市列表）
lib/docx.js           .docx 解析（基于本地打包的 JSZip）
lib/pdftext.js        .pdf 文字提取（基于本地打包的 pdf.js）
lib/profile.js        文本 → 结构化资料（标签配对、章节、正则兜底、省市拆分）
lib/textutil.js       文本/日期工具
vendor/               JSZip、pdf.js（本地打包，无需联网）
data/                 资料文件目录（info.docx / resume.pdf）+ manifest.json
test/                 示例网申表单
icons/                插件图标
```

主要技术点：

- **文档解析**：`.docx` 按 zip 解出 `word/document.xml`，按 `<w:p>`/`<w:tbl>` 顺序提取段落与表格；`.pdf` 用 pdf.js 提取文本并按坐标聚合成行（含空格还原）。
- **资料抽取**：先做「标签: 值」配对（支持一行多字段、表格行、PDF 拼接行），再做章节块解析（教育/实习/项目/获奖…），最后用正则兜底（手机号、邮箱、身份证、民族、政治面貌），并自动拆分籍贯/住址的省市区、由出生日期推算年龄。
- **表单填写**：把控件周围的标签（`label[for]`、包裹 label、Element/Ant 组件结构、表格 `th`/左侧单元格、前一个兄弟节点、`placeholder`、`name/id`、`aria-label`）收集成候选文本，与字段字典打分匹配；写入时用原生 value setter + `input`/`change` 事件，兼容 React/Vue 受控组件；下拉框按选项文本匹配（内置「本科=大学本科」「党员=中共党员」等等价词），单选框按选项文字选择，日期按控件类型/占位符自动格式化。
- **跨框架**：内容脚本注入所有 frame，顶层悬浮窗通过 `postMessage` 广播填写指令，各 frame 填写各自 DOM 后把结果汇总回顶层面板。
