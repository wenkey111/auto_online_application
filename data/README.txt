【资料文件放这里，插件会自动读取】

两种用法，任选其一：

用法一（推荐，最简单）：直接覆盖本目录下的示例文件
    info.docx    -> 你的网申信息文档（Word，.docx）
    resume.pdf   -> 你的简历（PDF）
  覆盖后，打开网申页面，在悬浮窗点「↻ 重新读取文件」即可识别新内容；
  悬浮窗也会自动检测文件是否变化（按文件内容哈希判断），无需重装插件。

用法二：使用你自己的文件名
  修改同目录的 manifest.json，把文件名改成你自己的，例如：
    {
      "info": "我的信息表.docx",
      "resume": "张三-简历.pdf"
    }
  改完后在 edge://extensions 点一下本插件的「重新加载」，或点悬浮窗的「重新读取文件」。

说明
  * 支持 .docx（Word 2007+）、.pdf（可复制文字的 PDF）、.txt / .md。
  * 旧版 .doc 请先在 Word 里「另存为 .docx」。
  * 扫描件 PDF（图片型）无法提取文字，请换成可复制文字的 PDF。
  * 也可以在悬浮窗 / 设置页里直接「上传」文件，上传的文件会长期保存在插件内，
    并优先于本目录的文件使用（可在设置页切回目录文件）。
